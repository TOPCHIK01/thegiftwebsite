Сюда клади фотографию кота для сцены «Ещё один подарок».

Название файла любое — подхватится первый найденный:
cat.jpg, cat.jpeg, cat.png, cat.webp …

Важно: iPhone может отдавать фото в формате .heic —
браузер его не покажет. Конвертируй в jpg
(на iPhone: Настройки → Камера → Форматы → «Наиболее совместимый»,
или просто перешли фото себе — оно придёт как jpg).

Необязательно: confetti.mp3 — короткий звук при открытии сцены
(ogg / wav / m4a тоже подойдут). Без файла сцена просто молчит.
