Звуки для игры «Маленькое приключение».
Положи сюда файлы с этими именами — игра подхватит их автоматически:

  jump.mp3        — прыжок
  collect.mp3     — сбор сердечка/подарка
  hit.mp3         — получение урона
  checkpoint.mp3  — активация чекпоинта
  stomp.mp3       — прыжок на врага («пуф!»)
  win.mp3         — открытие финального подарка
  game-music.mp3  — музыка уровня (играет по кругу)

Поддерживаются форматы: mp3, ogg, wav, m4a.
Пока файлов нет — игра просто работает без звука.
